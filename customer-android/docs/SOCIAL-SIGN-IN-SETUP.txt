BUBBLY-FI CUSTOMER SOCIAL SIGN-IN SETUP
=======================================

The Customer Android app uses an explicit Google OAuth flow and handles both
successful token redirects and readable provider errors. Facebook sign-in was
removed in Customer 1.6.22. The following remote provider settings are also
required; they cannot be embedded in an AAB.

Supabase Dashboard > Authentication > URL Configuration
- Add this exact redirect URL: bubblyfi://auth-callback

Supabase Dashboard > Authentication > Providers
- Enable Google and enter the Google web OAuth client ID and secret.

Google Cloud Console > OAuth web client
- Authorized redirect URI:
  https://amjhrejmcnthlrqddznw.supabase.co/auth/v1/callback

The Android manifest already accepts:
bubblyfi://auth-callback

The Google button uses Supabase browser OAuth, so an Android Google OAuth client
is not required for this implementation.
